# 书本造型预览

预览入口：design-system/book-shapes/index.html。正式小程序未修改。

- A 平展精装书：等宽平行书皮、双页中缝、无边框类型小字。
- B 线装册：左侧装订线、平整纸面、矩形印章类型标识。
- C 环装学习册：两张独立纸页、中央装订环、切角页签类型标识。

首次使用标题为“粤语童谣时光屋”，最近学习示例为“月光光”和“童谣”。标题使用相同的两行高区域，资源类型占位保持布局，角色与播放按钮也采用同一尺寸和位置。三角图标直接取自 Phosphor 官方 play-duotone.svg，许可证与来源哈希保存在 assets 和 play-source.json。

书本主体重新构建，外框未使用倾斜或透视变换。四个章节保留为可点击导航；浏览器中点击显示对应栏目清单，以便检查导航区域，未模拟完整游戏和资源播放。

小字统一霞鹜文楷 TC，大标题和章节标题保持马善政楷体。透明底月亮阿霖沿用上一轮素材。
