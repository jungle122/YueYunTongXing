# 真实装订线预览

上一版为自行绘制的几何示意，没有按真实针法复刻。其连续斜线不应作为四眼订的依据。

本次预览仅替换孔位和正面可见线迹，不更改书本主体、字体、配色和页面布局。入口：design-system/binding-study/index.html。

- 四眼订：4个主孔，纵向连接，逐孔绕书脊。
- 康熙订：4个主孔及首尾2个角部辅助孔。
- 龟甲订：4个主孔，每个主孔增加上下2个辅助孔。
- 麻叶订：4个主孔与5个辅助孔，首尾角部及孔间形成连续叶形。

主要图解由制作者 Papercraftpanda 发布：
https://blog.papercraftpanda.com/how-to-make-book-japanese-stab-binding-history-patterns-technique/

康熙订另核对装帧师 Eric Alstrom 在 Guild of Book Workers 的2013年讲义，尤其第2、5页的孔位和缝线说明：
https://guildofbookworkers.org/sites/default/files/standards/2013_EricAlstrom.pdf

实物参考：
https://boundbyhand.co.uk/blogs/news/make-japanese-stab-stitch-books

原始图解仅供参考核对，预览不使用来源图片作为产品素材；界面线迹按图解转绘，背面线段不显示，不作为完整穿针教程。逐项来源和孔位坐标保存于 sources.json。

已检查320/375/430宽度、首次与最近学习两种状态：四版书本边界一致，无横向溢出或图片加载失败；孔位数量及每段线迹的端点均为穿孔或书边。入口静态检查无FAIL、REFLEX或WARN。正式页面未修改。
