仅生成独立预览，不修改小程序正式页面。保留已确认的 Phosphor 双色图标、入口图标放大与透明背景效果，以及现有字号。

- A 书页标题：去掉背景框，以留白、细线和标题形成层次。首页最近学习使用开放式入口。
- B 书签题签：用窄书签表示章节或学习入口，标题在纸面排布。
- C 目录栏：章节、标题和入口信息分栏排列，纵向占用更少。

预览入口：`design-system/header-comparison/index.html`。

可切换学习天地、首页、学习统计。首页含首次使用和有学习记录两种状态，学习数据仅为展示样例。选定后再统一迁移到其他 Tab 页面及相关标题区，并接回现有导航与最近学习逻辑。

检查结果：三套方案在 320、375、430 宽度下均无横向溢出和图片加载失败；已查看学习页及首页两种状态的截图。Hallmark 对比入口检查无 FAIL、REFLEX 或 WARN。自带渲染器缺少依赖，改用 Playwright 浏览器完成截图与检查；这些不是微信原生运行截图。
