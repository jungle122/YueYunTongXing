# 建议、评分和项目方反馈管理

## 使用流程

用户从“我的 → 建议反馈”进入，可以提交小程序整体体验1至5星、建议文字或两者一起提交。评分可取消，联系方式选填。旧客户端仍能只提交文字，旧记录不自动填分。

反馈和评分继续存入现有 CloudBase `feedbacks` 集合，不新增服务器数据库或把反馈转发给第三方。项目方从反馈页底部“项目方反馈管理”进入，可按状态、星级筛选，分页查看建议、联系方式及评分，设置待处理/处理中/已解决并回复。用户可在自己的反馈记录中看到回复。

本次是本地代码实现，未部署云函数，未变更服务器、域名解析或证书，未在微信开发者工具和真机验收。管理员身份、云数据库查询索引和权限仍需在实际环境配置验证。

## 管理员怎么判定

云函数从微信上下文取得当前账号的 OpenID，与 `manageFeedback` 云函数环境变量 `FEEDBACK_ADMIN_OPENIDS` 比对。每一次读取全部反馈或修改状态、回复，都重新检查管理员名单。

OpenID 是用户在这个小程序内的标识，不是微信号。昵称、头像、前端传入的 `isAdmin`、`role` 或 `openid` 都不能授予权限。知道管理员的 OpenID 也不能仅靠它登录。授权依据是微信服务端提供的当前身份。

所有用户都能打开管理入口，但未授权者只能查看自己的授权标识及无权限提示，看不到其他人的反馈。入口是否显示不承担安全边界。

## 首次开通步骤

1. 确认 `feedbacks` 集合已存在，权限保持“所有用户不可读写”。不要为了管理方便改成公开读取。
2. 部署更新后的 `submitFeedback`、`listMyFeedback`，以及新增的 `manageFeedback`，选择“上传并部署：云端安装依赖”。
3. 在开发者工具编译小程序，通过开发预览或体验版让项目方账号进入“我的 → 建议反馈 → 项目方反馈管理”。
4. 项目方点击“复制我的授权标识”，交给负责维护的人。这个标识不是密码，不必提供微信密码或云账号密码。
5. 维护者在 `manageFeedback` 的云函数环境变量中设置 `FEEDBACK_ADMIN_OPENIDS=该标识`。多人用英文逗号分隔。保存并确认环境变量在运行实例生效。
6. 项目方点击“重新检查权限”，进入反馈列表。以后只需正常打开小程序，不需要操作代码或云控制台。
7. 撤销权限时，从服务端名单中移除对应标识并使配置生效。不要让普通用户自行修改名单。

没有配置管理员名单时，默认所有账号都没有管理权限。前端不会保存管理员凭据，也不存在默认管理员密码。

## 数据和索引

每条反馈新增可空的 `rating` 字段，取整数1至5；未评分为 `null` 或历史字段缺失，不按零分处理。这里是整体体验评分，不是模型回答质量、发音成绩或应用商店评分。

继续使用现有用户查询索引：`openid` 升序、`createdAt` 降序。管理员列表如遇缺少索引提示，按实际筛选建立以下组合索引：

- `status` 升序、`createdAt` 降序。
- `rating` 升序、`createdAt` 降序。
- `status` 升序、`rating` 升序、`createdAt` 降序。

后台每页20条，按提交时间倒序。分页期间有新反馈进入时，页码分页可能出现记录位置变化，刷新可回到最新第一页。当前未实现均分统计、批量导出、删除或向邮件/群聊发送通知。

建议和联系方式只供授权项目方查看，不展示在公开社区。回复仅回到用户自己的反馈记录。表单联系方式选填，避免要求儿童填写个人信息。

## 是否使用现有轻量服务器

本版管理页在小程序内运行，使用现有云开发，无需轻量服务器或新域名。

如果后续需要电脑网页后台，可以继续使用同一台轻量服务器，通过独立子域名和 Nginx 站点承载，例如 `admin.example.com`。绑定了一个在用域名，并不代表只能部署一个站点；是否适合增加服务，需要先检查内存、磁盘、当前站点和证书配置。子域名需有匹配的 HTTPS 证书，不能假定主域名证书自动覆盖子域名。

网页后台还需单独实现登录、服务端授权和安全的数据访问接口，不能把云数据库管理密钥写进网页。当前没有改动任何生产服务器配置，也没有部署网页后台。

参考：https://nginx.org/en/docs/http/server_names.html
