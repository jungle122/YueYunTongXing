# AI 童谣和文化讲解

## 当前实现与验证边界

已在童谣播放器和文化文章阅读页增加“问问阿霖 · AI 讲解”。第一版是单次文字问答，根据当前内容讲解；不接收录音、图片或历史聊天，不使用联网搜索或向量数据库。现有素材继续按用户授权作为可用素材，功能先于界面重构。

请求路径：原生组件 → `aiExplain` 云函数 → OpenAI Chat Completions 兼容的模型服务。这里的 OpenAI 指接口协议，不代表必须购买 OpenAI 服务。

默认适配阿里云百炼 `qwen-plus`；可通过配置切换 DeepSeek 或其他兼容服务。实际可用模型、权限和额度取决于账号。网页聊天会员、阿里云账号或其他产品的订阅，不等于已经开通模型 API。

当前本地13项测试通过，覆盖鉴权和配置、输入/输出检查、限额、服务商响应、重复点击、切换内容与退出组件。没有配置真实 API Key、调用付费模型、部署云函数或进行微信开发者工具/真机验证。`AI_ENABLED` 默认关闭。API Key 不要发送到聊天、写入前端或提交 Git。

## 你需要准备什么

1. 服务商名称，例如“阿里云百炼”或“DeepSeek 官方”。
2. 服务商提供的 Base URL 和已开通的模型名称。这两项可以发给开发者核对，不要附密钥或带密钥的 URL。
3. 在服务商后台取得专用 API Key，自己填写到下面的云函数环境变量。百炼密钥与 Base URL 要属于同一地域和计费方案。

首轮建议使用官方接口。中转服务也可配置，但需自行确认其处理数据、计费和模型来源；不会自动把官方 Key 交给中转站。

## 云端配置步骤

1. 打开本项目的微信云开发控制台，确认环境与 `app.js` 的 `wx.cloud.init` 一致。
2. 创建文档数据库集合 `aiUsage`，权限设为“所有用户不可读写”，仅云函数通过服务端 SDK 访问。
3. 在微信开发者工具中右击 `cloudfunctions/aiExplain`，选择“上传并部署：云端安装依赖”。保留同目录 `config.json` 中 `security.msgSecCheck` 权限。
4. 将该云函数超时时间设置为 60 秒，配置下面的环境变量。控制台入口名称随版本可能变化，通常位于云函数的配置/环境变量中。
5. 开发测试时可配置 `AI_TEST_OPENIDS`，仅允许列出的体验用户；服务端以微信上下文判定身份，不接受前端传入 OpenID。可从自己已有的用户资料记录或服务端调试上下文确认测试账号的 OpenID，不必发送到聊天。
6. 在服务商后台设置可用的额度/预算告警后，再将 `AI_ENABLED` 设为 `true` 做真实联调。保存配置后确保新配置已在函数实例生效。

### 阿里云百炼（默认）

| 环境变量 | 值 |
| --- | --- |
| `AI_ENABLED` | `true`，不配置则关闭 |
| `AI_PROVIDER` | `dashscope` |
| `AI_MODEL` | `qwen-plus`，或确认支持非思考模式的已开通千问模型 |
| `AI_BASE_URL` | 北京地域原有共享域名：`https://dashscope.aliyuncs.com/compatible-mode/v1`；也可以填写控制台提供的同地域业务空间专属 Base URL |
| `AI_API_KEY` | 在云函数控制台填写真实 Key，不提供给前端 |
| `AI_TEST_OPENIDS` | 可选，多个测试用户用英文逗号分隔；留空表示所有调用者均可请求，仍受次数限制 |

北京以外的 Key 不要使用北京示例地址。这里填写 Base URL，不要包含结尾的 `/chat/completions`。代码会追加该路径。

### DeepSeek 官方

`AI_PROVIDER=deepseek`，`AI_BASE_URL=https://api.deepseek.com`，`AI_MODEL=deepseek-flash`，并填入对应官方 `AI_API_KEY`。当前接口文档示例使用该模型，真实开通情况以控制台为准。代码禁用思考模式以优先取得简短最终答案。

### 其他兼容服务

`AI_PROVIDER=custom`，显式设置 `AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY`。必须支持 HTTPS 的非流式 `/chat/completions`，输入为 `messages`，最终正文从 `choices[0].message.content` 返回。不保证所有声称兼容的接口都能直接使用，需真实联调。

## 使用和数据处理

打开一首童谣或一篇文化文章，展开 AI 讲解，选择示例问题或输入200字以内的问题。确认问题处理说明后提交。

模型服务接收当前歌词/文章和本次问题，不接收微信 OpenID、昵称、头像、录音、学习记录或历史对话。微信文本检查服务检查问题和最终回答时会使用 OpenID。当前实现不保存问题和回答，不主动输出包含这些内容的日志；第三方服务的数据保留规则仍取决于供应商配置和条款。

回答明确标识 AI 生成，并注明“参考项目材料”，不声称模型完成独立考证或精确文献引用。当前文章本身也需要内容核对，接入模型不会自动纠正全部材料。系统提示词约束任务范围，但不能视为绝对防止幻觉或提示注入的保证。

后台默认每个用户每日最多20次、全应用每日最多200次、同用户间隔至少10秒；按北京时间自然日计数。限额在数据库事务中预占，模型调用或后续内容检查失败也不退还，避免失败重试造成无限费用。这是请求数限制，不等于人民币预算。`aiUsage` 只存日期、身份哈希、次数和最近请求时间；后续可清理旧日计数。

## 测试与维护

本地运行，不需要真实密钥：

```powershell
node --test cloudfunctions/aiExplain/test/*.test.js
```

服务端只按预置的 `contentType + contentId` 读取材料，不相信前端提供的文章、系统提示词、模型名、访问地址或用户身份。

材料快照包含现有6首童谣和4篇文章。修改歌词或文章后运行并重新部署云函数：

```powershell
node scripts/build-ai-materials.cjs
```

真实联调应确认：正常问答；关闭开关；错误密钥/地域；模型超时；文本检查异常；连续点击；切歌后旧结果不串页；退出页面后请求结果不再更新页面。数据库事务、文本检查权限、模型响应和真机布局尚需在自己的云环境验收。

输入/输出文本检查不可用、限额存储不可用时均停止模型回答。模型请求18秒超时，不自动重试或切换服务商；客户端45秒等待超时不代表服务端已取消。

公开上线前仍应在小程序后台确认主体与服务类目允许提供生成问答，并补齐实际使用服务对应的隐私说明和平台要求。本地接入和测试不等于已取得上线资格。
