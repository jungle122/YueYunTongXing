# C方案首页细化

入口：`design-system/c-polish/index.html`。正式页面保持不变。

- 大标题及少量章节标题继续用马善政楷体。
- 小字并列比较霞鹜文楷 TC 与本机宋体。宋体通过 local(SimSun) 使用 Windows 已安装字体，没有复制或分发系统字体文件。
- 有记录状态显示“月光光”和“童谣”标签，按钮为“继续学习”；首次使用按钮为“开始学习”。
- 按钮采用深陶土红、Phosphor 双色图标，以及按下变色和1px位移反馈。
- 月亮阿霖经 imagegen 背景移除后另存为透明 PNG。原图不变，透明通道检查通过，去掉原先 CSS multiply 白底融合。
- 书本没有设置梯形变换。原有底部更大的圆角、纸页层旋转和较重投影可能共同造成底部外扩的观感。本次统一书皮上下圆角、移除纸页旋转、缩窄书脊并减轻阴影。

已验证：两种字体实际加载、两种首页状态、320/375/430宽度无横向溢出和图片加载失败、书皮上下圆角一致、纸页无旋转、按钮按压状态及素材查看弹窗。以上为浏览器预览，不是微信原生验收。
