# 界面配色规范

沿用“粤语童谣时光屋”的暖色故事书风格。共享色板位于 `styles/theme.wxss`，由 `app.wxss` 引入。

## 基础颜色

| 用途 | 变量 | 颜色 |
| --- | --- | --- |
| 页面背景 | `--color-bg` | `#fffdf5` |
| 卡片与书页 | `--color-surface` | `#fffef8` |
| 次级底色 | `--color-surface-soft` | `#faf3e5` |
| 标题与正文 | `--color-text` | `#49352d` |
| 辅助说明 | `--color-text-secondary` | `#765f54` |
| 日期、计数与占位文字 | `--color-text-muted` | `#806b60` |
| 卡片边框与分隔线 | `--color-border` | `#ead8bc` |
| 输入框边框 | `--color-border-strong` | `#cbb8a2` |
| 书皮与装饰 | `--color-brand` | `#cf684b` |
| 主操作、链接与选中项 | `--color-primary` | `#a94736` |
| 主操作按下状态 | `--color-primary-pressed` | `#8f3c29` |
| 禁用背景 | `--color-disabled-bg` | `#efe2d0` |
| 禁用文字 | `--color-disabled-text` | `#806b60` |

主按钮采用深陶土红配白字。普通链接使用主操作色。装饰色不直接用作小字号正文颜色。

## 状态与章节

| 用途 | 文字色 | 浅色背景 |
| --- | --- | --- |
| 成功、已完成 | `--color-success` | `--color-success-soft` |
| 错误、失败 | `--color-error` | `--color-error-soft` |
| 注意、待处理 | `--color-warning` | `--color-warning-soft` |
| 信息、处理中 | `--color-info` | `--color-info-soft` |

状态色配合文字、图标或边框使用。保留游戏中已有的正确、错误和提示标记。

学习、游戏、原创和个人成长栏目保留原有黄、绿、玫瑰与蓝色的插画氛围。章节色用于内容分组、书签和装饰。保存、发布、重试、播放等主操作统一使用陶土红。

微信头像与昵称入口保留微信绿。入口文字使用 `--color-wechat-text`，边框与浅底分别使用对应的微信色变量。

## 使用约定

- 修改同类颜色时优先修改共享变量。
- 原生导航栏、TabBar、slider 颜色属性与确认弹窗使用十六进制颜色，与共享色板保持一致。
- AI 讲解组件提供变量默认值，以支持独立引用。
- 封面插画、纸张纹理、投影透明度和游戏内容渐变保留原有表现，不作为新增通用控件的配色来源。
- 界面文案不使用中点作为分隔符。并列内容使用顿号，动态摘要使用逗号，补充信息使用括号。

本次检查覆盖变量引用、模板标签、改动脚本语法、原生配色一致性及关键文字配色的对比度。实际显示效果仍需在微信开发者工具和真机中确认。
