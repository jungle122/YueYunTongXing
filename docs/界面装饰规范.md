# 界面装饰规范

沿用书本与童谣时光屋的视觉概念，减少通用组件的装饰。

| 组件 | 圆角变量 | 大小 |
| --- | --- | --- |
| 普通卡片与内容容器 | `--radius-card` | 24rpx |
| 按钮与输入框 | `--radius-control` | 16rpx |
| 标签与章节印章 | `--radius-label` | 8rpx |
| 弹窗与浮层 | `--radius-overlay` | 24rpx |

圆形头像、图标、进度条、首页书皮和书页拼接角保留原有造型。

普通卡片、入口、按钮和缩略图不再使用投影，依靠边框、底色与间距区分。按压仍保留现有缩放或透明度反馈。

弹窗、播放器浮层、悬浮阅读工具和消息提示可保留阴影。游戏中的目标提示、选中拼图及当前接龙位置保留有任务含义的高亮。首页书皮、书脊、书页与书签的阴影保留，用于表现书本层次。

学习、游戏与原创入口的左侧彩色粗线移除。历史记录、收藏列表保留4rpx分类色条，并使用一致的类型颜色。歌词排序提示色条保留，用于标识提示；绘本歌词框的装饰色条移除。
