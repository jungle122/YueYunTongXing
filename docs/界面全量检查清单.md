比较页：`design-system/icon-comparison/index.html`。取自当前学习页、首页和学习统计的 WXML/WXSS；数据是展示数据，浏览器预览不是微信原生截图。素材原始文件和 LICENSE 保存在对应 assets 目录，下载来源和 SHA256 见 sources.json。

建议优先看 C，色彩统一后更贴近故事书；A 最克制；B 更偏工具界面。候选之间不混用。头像插画、绘本和视频封面保留为内容素材。
