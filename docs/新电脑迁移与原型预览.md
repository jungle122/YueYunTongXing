# 新电脑迁移与原型预览

当前开发分支：`codex/home-prototype-refine`。请拉取此分支，原型代码和正式小程序在仓库中，原型素材需从 U 盘恢复。

```powershell
git clone --branch codex/home-prototype-refine https://github.com/jungle122/YueYunTongXing.git
cd YueYunTongXing
python -m http.server 8765 --bind 127.0.0.1
```

安装 Python 3 后，在项目根目录启动上述服务，打开：

- 两页当前前后对比：http://127.0.0.1:8765/design-system/material-study/preview.html
- 学习天地 A：http://127.0.0.1:8765/design-system/material-study/index.html
- 原创剧场 A：http://127.0.0.1:8765/design-system/original-preview/index.html
- 逐页进度：`design-system/app-prototype/progress.json`

学习天地当前为 A 横向手账，保留精修科普抠图、文楷学习足迹、脚印及数量，无进度条。原创剧场保留矩形拼图与浅米色胶片纸纹，已移除手册标题后的贴片。每页仍需用户确认，不自动进入下一页。正式小程序页面本轮未改。

原型 CSS 和脚本随仓库保存；图片、SVG、字体等不上传 GitHub。请完整备份 design-system 文件夹，新电脑拉取后原路径合并复制回来。不要只复制当前页面目录，以免遗漏公共字体和素材。项目 static 目录已由 Git 跟踪，原型引用的绘本内页无需另外补齐。历史素材处理脚本中的 `C:/Users/.../Temp` 只记录原始参考来源，日常预览不需要这些临时附件；不要直接重跑历史构建脚本覆盖当前版本。素材授权记录保留在各原型目录的 sources 文件中。

微信开发者工具直接导入项目根目录，按原 README 配置云环境。`project.private.config.json`、`.env`、密钥、日志、node_modules 和本机工具配置不上传，换电脑后需自行配置或重新安装。Codex 全局 skills 和聊天记录不属于本项目，需在新电脑单独配置；当前设计进度已保存在仓库中。

仅就原型预览而言，备份整个 design-system 即可。本机 project.private.config.json、Codex 全局 skills、微信开发者工具登录状态不包含在该文件夹内；若需要延续个人环境，请另行备份或在新电脑重新配置。
