# 文章阅读原型

- `index.html?id=文章ID`：四篇文章共用阅读页；收藏、阅读进度、讲解折叠均可操作。
- `compare.html`：四篇文章可切换；390 × 844 同篇同状态对照。
- `before.html`、`before.css`、`before.js`：保留的一份早期无插画历史对照，不是本轮已弃用的插画版。
- `articles.json`：原文数据，未修改。
- `reader.css`：标题页角、知识旁注裱边、书签与细分隔；无插画。
- `sources.json`：当前实际使用资源的来源和授权。
- `check.cjs`：检查四篇原文、三档宽度、收藏、讲解折叠和阅读进度。
