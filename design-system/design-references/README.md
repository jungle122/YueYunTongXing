只改状态与参考材料，未修改任何原型页面。学习天地已撤回确认，旧版本全部保留。

FreeDesign：https://github.com/AIPMAndy/FreeDesign 。已读取 README。它是资源导航，包含 Dribbble、Mobbin、图标、字体、插画与组件等入口；仓库 MIT 不代表链接资源统一采用 MIT。此轮没有下载素材加入产品。

本轮4个案例见 index.html 与 sources.json，官方商店展示图可能包含宣传框，不能当成原生运行截图。图片外链至来源，没有作为产品资产使用。

检索建议：
- 站酷：国风 APP 界面、文创 小程序、儿童教育 拟物 UI、岭南文化 UI。
- Behance：Chinese culture app UI, museum app design, kids learning app, editorial mobile UI。
- Dribbble：skeuomorphic learning app, paper UI, storybook app, tactile interface。
- Pinterest：storybook app UI, warm paper interface, Chinese editorial design；优先点回原创来源。
- Mobbin：education、reading、kids；参考真实流程与信息层级，不默认其视觉符合岭南主题。

筛图标准：优先完整手机页面、能看到标题与两个主要入口、温暖但清楚易读、物件承担导航或内容；排除仅孤立图标、海报、纯3D摆件、玻璃渐变和过度装饰。先选一个主参考再设计，不拼贴现成界面。
