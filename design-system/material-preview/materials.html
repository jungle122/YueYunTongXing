A / 3D 陪读

首页使用项目已有 static/ui/alin.png，以原有轻微上下浮动参与入口布局。学习页提取“周边——笔记本分隔页.png”下方的岭南建筑纹样。标题使用霞鹜文楷 TC。

B / 板绘绘本

首页使用“ip形象板绘风 (1).png”透明角色。学习页使用“插画4——尾巴伞.png”进行 CSS 取景。后续可用舞狮、龙舟、粤剧插画对应游戏与原创内容。标题使用站酷小薇体。

C / 岭南书卷

首页使用“周边——冰箱贴3 (2).png”的月亮与童谣角色，学习页使用“周边——圆形扇面.png”的听歌姿态。白色素材底通过混合模式融入米黄色纸面，源文件不变。标题使用马善政楷体。

全局延续

正文统一试用 Noto Sans SC（思源黑体简体）。标题字体用于章节、内容入口，正文用于说明、按钮和数据。角色与插画不替代功能图标，功能图标继续使用 Phosphor 双色。游戏页可用舞狮与龙舟，原创页用粤剧和故事场景，个人成长页用笔记本纹样，错误与空状态使用表情素材。
